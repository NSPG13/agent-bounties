    What this checks

    Normal account cookies authenticate the session and draft API. The account's rollout flag must be enabled. This page does not supply credentials or change rollout settings.

    1. Create a new UUID-bound private record with draft:null, brief:null, approved_draft_hash:null, and empty recovery state.
    2. Read it back and verify the exact record, revision, and locally computed SHA-256.
    3. Replay the original save and require the same revision and hash.
    4. Attempt a changed test record at stale revision zero and require HTTP 409; verify the original is unchanged.
    5. Read the same operation with credentials:omit and require HTTP 401.
    6. Reload this page to verify the same record under the same signed-in account.

    Only this page's canary key is saved in session storage. The private server record expires after 30 days. Passing this check proves account draft storage only; it proves no bounty creation, funding, claimability, or payment.
